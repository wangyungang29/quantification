二、通用代码提示词模板（直接可用）
✅ 提示词 1：缠论完整解析器（推荐）
提示词：
“请基于缠论（Chan Theory）编写一个完整的行情分析模块，包含以下功能：
对原始K线进行包含关系处理，生成标准化K线；
识别顶分型和底分型；
连接分型生成笔（Pen），并过滤无效笔；
由笔构成线段（Segment）；
自动识别中枢（Zigzag Overlap）；
判断第一类、第二类、第三类买卖点；
输出买卖信号、止损位、中枢上下沿。
要求：逻辑严格符合缠论原文，避免未来函数。”
✅ 提示词 2：只做“买点提示”的轻量版
提示词：
“请用代码实现缠论中的买入信号检测：
仅识别一买（趋势背驰）、二买（回调不破前低）、三买（中枢上沿不回踩）
使用MACD或均线辅助验证背驰
输出：信号类型、触发价格、止损价
适用于股票/期货日线级别”
✅ 提示词 3：Pine Script（TradingView）专用
提示词：
“写一个TradingView Pine Script v5指标：
自动绘制缠论笔和线段；
标记中枢区间；
当出现一买、二买、三买时，在K线上方/下方标注箭头；
不使用未来函数；
支持自定义周期。”
三、关键参数建议（写入代码）
# 示例参数
PARAMS = {
    "min_bars_pen": 3,        # 一笔最少K线数（缠论理论最小值，太高会导致近期数据无信号）
    "segment_strength": 3,    # 线段破坏所需笔数
    "central_overlap": 3,     # 中枢最小重叠段
    "macd_threshold": 0.5,    # 背驰判定阈值
}
四、常见坑（务必让AI避开）
✅ 禁止偷看未来数据
✅ 明确“确认”而非“预判”
✅ 区分“笔中枢”和“段中枢”
✅ 背驰必须对比两段走势
